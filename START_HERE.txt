INSTALL WITH GIT
1. Open a clean checkout of dunnigann/zynfl-site and pull main.
2. Extract this ZIP outside the checkout.
3. From the repository root, run:
   git apply --check /path/to/extracted/homepage-globe.patch
   git apply /path/to/extracted/homepage-globe.patch
   node --test zynfl-production/scripts/test-home-globe.cjs
4. Review, commit, and push to main. Existing Cloudflare Workers Builds deploys it.
   If git apply --check reports conflicts, stop and reconcile with newer edits.

ALTERNATIVE: Copy the included zynfl-production files into the corresponding paths
in your repo, preserving all other files, then commit/push. The ZIP contains only
the eight changed files, plus this readme and the patch. Do not upload the ZIP itself
as a website asset. No dependency installation or Cloudflare configuration needed.
