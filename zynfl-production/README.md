# ZYNFL

Production repository for the ZYNFL fantasy football league website.

## Structure
- `public/index.html` — site entry point
- `public/assets/css/` — styling
- `public/assets/js/` — league data and application code
- `public/assets/images/` — logo, manager photos, rivalry art, gallery
- `public/data/` — reserved for future automated live data
- `.github/workflows/` — validation/automation
- `scripts/` — helper scripts
- `HOSTING_GUIDE.md` — Cloudflare setup instructions
